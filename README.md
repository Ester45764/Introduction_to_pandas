# Introduction to Pandas

## What is Pandas?

Pandas is an open-source Python library for data manipulation and analysis. It provides powerful data structures, such as **Series** (one-dimensional data) and **DataFrame** (two-dimensional data), that make it easy to clean, transform, and analyze data from various sources, including CSV files, Excel spreadsheets, SQL databases, and JSON.
